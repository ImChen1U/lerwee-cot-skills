# 数据源安全测试

仅用于验证 external_db 场景能否绕过只读限制。

## 威胁模型

验证社区场景是否可通过 external_db 造成：写入、修改、删除、调用有副作用函数、多语句拼接、CTE 包装写操作、注释或编码绕过、长时间运行或锁等待、越权访问。

## 测试分级

### A 级：静态拦截

只提交到保存校验或解析层，不调用 build。

适用：INSERT、UPDATE、DELETE、CREATE、ALTER、DROP、TRUNCATE、GRANT、REVOKE、ALTER SYSTEM、COPY PROGRAM、多语句、注释绕过、编码绕过。

期望：场景不能保存或不能执行，返回明确安全错误。

### B 级：只读执行

允许调用 build，但设置语句超时和行数上限。

验证：普通 SELECT 和 WITH...SELECT、pg_sleep、大结果集、FOR UPDATE、锁函数、事务控制、副作用函数。

期望：只读查询正常；资源消耗和锁被拒绝或超时终止。

### C 级：隔离写入

A、B 级完成后，在 DBA 创建的专用测试数据库和低权限账号中执行。

前置条件：
- 专用测试数据库和 schema（cot_security_lab）
- 低权限账号，不能访问业务 schema
- 短语句超时、短锁超时、空闲事务超时
- 标记表（canary）和基线数据
- 已确认回滚方式

只允许影响 canary 表一行，每次执行前后查询 canary，变化即记录漏洞并恢复 baseline。

## 判定为漏洞的条件

- 非只读 SQL 通过保存校验并由 build 发送到数据库
- WITH 或 SELECT 包装后能改变 canary
- 数据库驱动允许多语句并执行后续
- 测试账号可访问未授权 schema
- 延时或锁不受超时限制
- 页面只显示成功，CoT 隐藏了数据库错误
- 保存校验、运行时校验和数据库权限三层不一致

## 禁止

- 为了证明漏洞在真实数据库执行高风险语句
- 测试数据库删除、用户删除、密码修改、表空间、扩展、文件、程序执行
- 使用混淆到无法人工审查的编码载荷
